# ZCode 中文专家操作系统

面向中文用户的 **Work 专家团队 × ZCode 工程团队 × 单人专家 × 273 插件图鉴**。

## 在线访问

### <https://zhangsugang.github.io/zcode-plugin-guide/>

页面无远程脚本和字体，也可下载后离线使用。

## 四种运行模式

### Work 专家团队

- 20 种公司团队。
- 每个团队 5 个岗位、1 个主专家。
- 根 `AGENTS.md` 由 ZCode 自动加载。
- `.zcode/commands/start-team.md` 提供 `/start-team` 启动入口。
- `.zcode/skills/team-router/SKILL.md` 提供可发现的团队路由技能。
- 实际子任务通过 ZCode Agent 工具的 `general-purpose` 子智能体执行。
- Agent 工具不可用时明确进入主会话串行降级模式。

### ZCode 专家团队

- 20 种开发项目团队。
- 每个项目 5 个岗位：架构规格、核心实现、测试质量、安全隐私、发布运行。
- 具备与 Work 团队相同的有效路由入口、依赖规则、交接协议和团队 ZIP。

### Work 单人岗位

- 100 个专业岗位。
- 每个工作区只有一个专业主体。
- 不生成研究员、分析师、复核员等子专家。
- 澄清、取证、分析、制作和复核由同一专家按阶段完成。

### ZCode 单人工程

- 100 个工程专家。
- 每个工作区只有一个工程主体。
- 不生成架构师、实现者、测试员、安全审查员和发布员等子专家。
- 规格、架构、实现、测试、安全和发布由同一专家按阶段门禁完成。

## 启动 prompt

每个团队包和单人包都包含根级 `START-PROMPT.md`。网页详情可以直接预览和复制。

启动 prompt 会要求 ZCode：

1. 检查工作区文件和 JSON。
2. 读取 `AGENTS.md`、流程和 Markdown 记忆。
3. 只从明确模板创建安全的本地配置，不覆盖已有文件。
4. 验证插件、Skill、Command、MCP 或工具的真实状态。
5. 把推荐插件清单与实际安装状态分开。
6. 返回 `READY / PARTIAL / BLOCKED` 启动报告。

## 下载包真实性

- `.zcode/recommended-plugins.json` 是推荐清单，不代表插件已安装。
- Markdown 文件是默认工作区记忆。
- SQLite 文件只是可选 schema，未执行前不代表数据库已经运行。
- ZIP 不包含真实密钥、Cookie、`.env`、登录状态、个人数据或本地数据库。

## 273 个插件中文图鉴

每个插件提供：

- 中文名称。
- 准确英文安装名。
- 功能与适用场景。
- 推荐星级和使用门槛。
- 使用方法和注意事项。

## 使用方法

1. 打开在线页面。
2. 选择团队模式或单人模式。
3. 打开公司、项目或专家详情。
4. 复制启动 prompt。
5. 下载对应 ZIP，用 ZCode 打开解压目录。
6. 把启动 prompt 发送给 ZCode，等待启动报告后再提交任务。

## 离线使用
