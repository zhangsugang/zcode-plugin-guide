# ZCode 中文插件图鉴

一个面向中文用户的 ZCode / Claude Code 插件选型控制台。

- 收录 273 个插件
- 17 个功能分类
- 中文名称、用途说明、适用场景和推荐星级
- 保留英文插件标识，方便回到 ZCode 精确搜索安装
- 支持中英文搜索、分类、星级、门槛和排序筛选
- 单文件 HTML，无外部依赖，下载后可离线打开

## 在线访问

**GitHub Pages：** <https://zhangsugang.github.io/zcode-plugin-guide/>

## 本地使用

1. 下载仓库中的 [`index.html`](./index.html)。
2. 双击文件，使用 Chrome、Edge、Safari 或 Firefox 打开。
3. 页面不会上传搜索内容或筛选记录。

## 推荐用法

- 不知道装什么：先看“个人页推荐插件对照”和五星推荐。
- 按工作找插件：点击能力频谱中的代码开发、设计、浏览器、数据库、云部署等分类。
- 对照 ZCode 安装：卡片中文标题解释用途，下面的英文等宽标识就是需要在 ZCode 中搜索的插件名。
