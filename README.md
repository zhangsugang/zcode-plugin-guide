# ZCode 中文插件工作台

面向中文用户的 **Claude Work × Codex 插件方案库**。不仅解释插件是什么，还告诉你完成一项工作或开发一个项目应该安装哪些插件、如何组合、实际过程是什么。

## 在线访问

### <https://zhangsugang.github.io/zcode-plugin-guide/>

直接把这个链接发给别人，浏览器打开即可使用。

## 核心内容

- **Work 模式**：20 个中国高频工作场景
  - 电商运营、直播与短视频、本地生活、销售、市场、客服
  - 数据分析、财务、人力、行政、法务、产品和项目管理
  - 教育培训、内容编辑、视觉设计、供应链、跨境电商、企业管理和行业研究
- **Codex 模式**：20 个常见开发项目
  - 企业官网、营销落地页、电商商城、管理后台、数据看板
  - AI 聊天机器人、RAG 知识库、微信小程序、移动应用和 API
  - 自动化机器人、AI Agent、客服、CRM、内容平台、爬虫、门店系统、SaaS 和支付订阅
- **273 个插件中文图鉴**：中文用途、分类、推荐星级、门槛和英文安装标识
- **40 套插件组合**：必装插件、进阶/专用插件、实际案例、4–7 步操作流程
- **重点插件图标**：复现 ZCode 推荐区中有明确名称的常见插件图标
- 支持职业、项目、案例、任务和英文插件名搜索
- 支持复制完整英文插件清单，回到 ZCode 精确搜索安装
- 支持 `#work/...`、`#codex/...`、`#plugin/...` 链接分享
- 单文件 HTML，无外部脚本和字体，下载后可离线打开

## 使用方法

1. 打开在线页面。
2. 选择 **Work 模式** 或 **Codex 模式**。
3. 搜索你要完成的工作或项目。
4. 打开方案，查看插件集合、实际案例和执行步骤。
5. 点击“复制全部英文插件名”，在 ZCode 插件页逐个搜索安装。

## 离线使用

下载仓库中的 [`index.html`](./index.html)，双击即可使用，不需要服务器或构建环境。

## 研究边界

场景结合公开的数字职业、互联网应用、招聘和企业数字化资料整理，定位为“2026 中国高频实用场景”，不是官方职业排名。页面不会使用无法直接核验的量化数字；业务案例是示例工作流，不代表真实客户业绩。
